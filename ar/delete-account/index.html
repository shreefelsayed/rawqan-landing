مهم

حذف الحساب نهائي. ستفقد الوصول إلى ملفك الشخصي والعناوين المحفوظة والمفضلة وسجل الطلبات في التطبيق، وبيانات متجر التاجر المرتبطة بالحساب. يُفضّل إكمال أو إلغاء الطلبات المعلّقة قبل الحذف.

1. حذف الحساب من التطبيق (موصى به)

  1. افتح تطبيق رواقان للعملاء أو التجار وسجّل الدخول.
  2. اذهب إلى الملف الشخصي / الإعدادات.
  3. اضغط حذف الحساب.
  4. أكّد الحذف عند الطلب. لا يمكن التراجع بعد التأكيد.

بعد التأكيد ننفّذ عملية حذف الحساب ونسجّل خروجك. ستظهر رسالة تأكيد عند اكتمال العملية بنجاح.

3. البيانات التي نحذفها عند حذف الحساب

عند اكتمال الحذف نزيل أو نُعمّي البيانات الشخصية المرتبطة بحسابك، بما في ذلك:

  • ملف الحساب (الاسم والبريد والهاتف وصورة الملف)
  • بيانات المصادقة / تسجيل الدخول لذلك الحساب
  • عناوين التوصيل المحفوظة ومواقع الخريطة
  • المفضلة وبيانات السلة
  • رموز إشعارات الدفع
  • تفضيلات التطبيق (مثل اللغة)
  • للتجار: بيانات المتجر وقوائم المنتجات المرتبطة بحساب التاجر (حيث لا تكون لازمة لطلبات مكتملة لمستخدمين آخرين)

4. البيانات التي قد نحتفظ بها

قد نحتفظ ببعض المعلومات لفترة محدودة عند الحاجة لأسباب قانونية أو أمنية أو محاسبية أو لحل النزاعات:

  • سجلات الطلبات / المعاملات المكتملة — للضرائب والمحاسبة ومنع الاحتيال وحل نزاعات التوصيل أو الدفع. قد نُقلّل أو نستبدل المعرّفات الشخصية حيث أمكن.
  • سجلات مالية / مدفوعات للتجار — حسب متطلبات المحاسبة والامتثال.
  • مراسلات الدعم المتعلقة بطلب الحذف أو نزاعات سابقة.
  • سجلات الأمان التي لا تعرّفك بما يتجاوز ما يلزم لاكتشاف الإساءة.

تُحفظ السجلات المحتفظ بها فقط طوال المدة اللازمة لتلك الأغراض (عادة حتى 24 شهرًا، أو أطول إذا تطلّب القانون المصري ذلك)، ثم تُحذف أو تُعمّى بالكامل.
